# Structuring

> [!WARNING]
> This book is **under development**. Some chapters are still incomplete and
> the content may change without notice.

In this chapter we focus on structuring our new `serde_ubj` project, by

* creating a good directory layout,
* defining both internal and user-facing Rust modules,
* scaffolding the build pipeline, and drafting the `Cargo.toml` manifest file,
* implementing the `UbjError` type for idiomatic error handling,
* and laying out test modules to be conditionally compiled.
