# Data Models

> [!WARNING]
> This book is **under development**. Some chapters are still incomplete and
> the content may change without notice.

In this chapter we clarify the concept of data models in general, and why we 
need to distinguish between the application and the Serde data models. 

> [!NOTE]
> In software engineering, a **Data Model** is a blueprint for organizing and
> structuring information within a software system. It defines what data the
> system tracks, the properties of that data, how different data points relate
> to one another, and the rules or constraints governing them.
